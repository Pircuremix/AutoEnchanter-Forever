# AutoEnchanter 1.5.0 — Customer database and business dashboard

Target: WoW Forever, interface 16001. Release candidate for live trade/UI acceptance.

## Added

- Account-wide local customer ledger with full character name, GUID, distinct invitation ID, original local full date/time, enchanter, and accepted/declined/expired/pending outcomes. Failed, unverified and overlapping requests are separate.
- Verified tip copper, completed item-enchant count and weighted average per item, both lifetime and per invitation. Expiry counts as decline.
- Read-only trade observer: final both-accepted snapshot and explicit completion required. Gold only and no outgoing items/money or incoming service/currency. Customer's non-traded enchant service does not disqualify tip. Separate payment supported during active visit. Unverified transactions excluded, never infer income from wallet delta.
- Dark dashboard with Overview, Customers and Settings, searchable/sortable/paginated customer list, invitation history, time and customer filters, local TSV export, confirmation for deletion/reset, saved position and scale.
- Minimal minimap icon with enabled dot, left dashboard, Shift-left toggle, dynamic two-item right menu; standard named Minimap child for EllesmereUI discovery.
- /ae database, dashboard, ledgerstatus, tradetrace, minimap show/hide; /ae settings and config open dashboard Settings. Native settings category remains.
- Business regression suite and modular Database.lua, Trade.lua, Dashboard.lua, Minimap.lua, schema and contributor documentation.

## Upgrade

Refresh WowUp, install update, restart WoW. Existing whitelist, settings, icon, category and optional group automation are preserved. Ledger begins empty; no historical backfill. Real AE invites automatically tracked (not debug). Existing accepted visits continue passive tracking when AE off. Click minimap icon or /ae database. /ae ledgerstatus reports evidence counters. /ae tradetrace on/dump/off is a bounded local diagnostic.

## Limitations and tests

Trade completion requires explicit localized success evidence; Forever live event ordering may differ and cause conservative undercounting. No credit for canceled or ambiguous trades; unverified records are flagged. No manual adjustment UI in this version. EllesmereUI Free Move Buttons intercepts Shift-left, so disable that mode to use the requested gesture. Stock minimap anchor fixed; EUI can reposition. Live dashboard rendering and client restrictions still require testing. SavedVariables persist on normal logout/reload, not necessarily on crash. Pending records resolve from observed membership; a real invite cannot be proven to have caused a specific join. No real customer data transmitted.

See GitHub Actions for tests on Lua 5.1/5.4 and ZIP verification. Existing matching/group suites retained; business suite exercises record lifecycle, money/item rules, UI model and minimap click dispatch.
