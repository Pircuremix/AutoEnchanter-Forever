# AutoEnchanter 1.4.0 — Customer welcome and raid management

Target: World of Warcraft: Forever (interface 16001). Release candidate for live-client acceptance.

## Added

- Customer acceptance correlation: a bounded session-only pending GUID tracker records successful native invite requests, then observes actual group membership. No welcome on invite alone or unrelated joins; one welcome per tracked join, 120-second expiry.
- Configurable welcome text and optional self-marker. PARTY or RAID is selected from the live group at send time. Supports {customer}, {player} and {zone}; one line, at most 255 bytes after expansion.
- Self-marker preservation: select any of the eight raid icons. Never removes or re-applies an existing self-mark, and skips if the selected icon is observed on another group member.
- Auto raid conversion: opt-in, threshold 3 including self by default (configurable 2–5), leader only, outside instances; no automatic conversion back. If conversion is pending, wait up to five seconds for a confirmed raid before choosing the actual current chat channel.
- Native Settings panel (/ae settings or /ae config) and slash fallbacks (/ae welcome, message, marker, raid, groupstatus).
- New account-wide settings, initialized safely with all three automations off; existing whitelist and flags retained.
- Group-specific counters and independent handling of restricted/blocked chat, marker and conversion APIs.

## Changed internally

Separated customer/group state and options into Group.lua and Settings.lua, loaded before the existing core via TOC. Kept the matcher, alias rules and invitation hot path intact. Added integration tests for acceptance, channels, ordering, marker protection, settings/migration and failure cases. Centralized test and packaging scripts; ZIP now includes all TOC-listed runtime modules. Added version-specific release notes, architecture contracts and AI/maintainer instructions. Release metadata continues to identify Forever for WowUp.

## Upgrade and activation

WowUp can update the package normally; no manual SavedVariables change is needed. Fully restart WoW so the TOC loads the new modules. Open /ae settings and enable each desired feature. Select threshold 3 and preferred icon, edit and save message. Check /ae groupstatus and /ae diagnostics. Debug suppresses real actions. Existing settings are account-wide.

## Testing and limitations

See GitHub Actions for automated Lua 5.1/5.4 regression and packaging results. Follow the live acceptance checklist in README.md before relying on unattended actions. Native APIs may restrict chat, marking or conversion; the addon respects confirmation prompts and does not retry blocked calls. Invite delivery, actual chat delivery, visual marker behavior and Settings rendering are not established by the mock suite. The welcome tracker correlates a GUID joining with an earlier request; Blizzard exposes no proof which particular invite caused membership. Auto raid affects ordinary manual parties too when enabled and can interfere with ordinary quest progress. No license change.
