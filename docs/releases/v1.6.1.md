# AutoEnchanter 1.6.1 — Dynamic welcome messages

## Added
- Case-insensitive CUSTOMER, MARKER, MARKER_NAME, PLAYER and ZONE brace placeholders for normal party/raid welcome messages.
- Actual self-marker read after optional marking; native numeric icon markup, English marker name, explicit fallback for absent or unreadable marker.
- Five insertion buttons and live local preview in shared welcome settings, plus /ae preview [customer name].
- Regression coverage for all eight icons, existing/failed/secret marks, mixed case, unknown tokens, size limits, preview isolation, insertion and delayed raid routing.

## Upgrade
Update with WowUp and restart WoW. Existing saved settings, customer history, schema 2 and guild whisper preserved. No migration required. Existing lowercase templates still work. Example: /ae message Hey {CUSTOMER}, find me at {MARKER}. Please open trade when you're ready.

## Scope and verification
No changes to invite matching, pre-invite path, guild whisper, database, blacklist, marker assignment or raid conversion. Templates only expand after acceptance; local previews never send. Actual icon display and live settings layout require in-game verification. See [welcome message guide](../WELCOME-MESSAGES.md), [changelog](../../CHANGELOG.md), and GitHub Actions for tests.
