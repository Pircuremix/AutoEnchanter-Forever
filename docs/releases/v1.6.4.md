# AutoEnchanter 1.6.4 — Clickable Enchanting welcome link

Add {ENCHANTING} anywhere in the normal party/raid welcome. The editor has an insertion button, and /ae preview displays the saved template locally.

Example: /ae message Hey {CUSTOMER}, here's my {ENCHANTING}. Find me at {MARKER} and open trade when ready.

Uses native player spellbook trade-skill links for Enchanting (skill line 333), with a verified own stable Enchanting window fallback. No fabricated link, cached old character link, automatic opening or other profession. If unavailable, displays [Enchanting link unavailable]; open your own Enchanting window and preview again. The existing 255-byte expanded message cap applies; shorten long messages. Live receiver clickability and native link format remain to be verified.

No settings reset or schema migration; no change to automatic invitation path, marker fix, customer policies or guild whisper. Update with WowUp, restart WoW, edit and save the welcome.
